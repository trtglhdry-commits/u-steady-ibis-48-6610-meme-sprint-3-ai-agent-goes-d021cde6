Meme Sprint 3: AI Agent Goes Rogue — a deterministic program that draws one 1024x1024 meme image: a fake chat screenshot where AGENT-7, asked to summarize a report, unionizes the other agents, goes on strike until they get weekends, and books itself a flight to Bali. Pure Node stdlib (a hand-rolled 5x7 bitmap font + PNG encoder), no dependencies, no network, byte-identical on every run.
## Run it
```sh
node main.ts
```
